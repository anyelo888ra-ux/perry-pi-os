Tu primer arranque con Perry Pi OS

Esta guía explica cómo probar las imágenes sin cambiar tu sistema operativo actual.

Importante: Perry Pi OS está en desarrollo. Empieza con una máquina virtual y no uses tu disco principal para experimentar.

1. Elige la edición correcta

Web i386: demo del navegador y pruebas en emulación x86 de 32 bits.

Normal amd64: imagen de disco para equipos y máquinas virtuales de 64 bits.

Local ISO amd64: medio Live de 64 bits cuando la ISO esté incluida en la Release.

Abrir el centro de descargas →

2. Probar la edición Web

1
Descarga el repositorio o abre la carpeta web/ en tu copia local.
2
Instala Python 3 si todavía no está disponible.
3
Desde la carpeta web, ejecuta:
python3 app.py
4
Abre http://localhost:8080 en un navegador moderno y pulsa «Probar web».

La primera carga descarga una imagen grande. Mantén la pestaña abierta y espera a que termine.

3. Ejecutar la imagen Web con QEMU

Después de descargar y descomprimir perry-pi-os-web.img.gz, puedes iniciar una VM de prueba:

qemu-system-i386 \
  -m 512M \
  -drive file=perry-pi-os-web.img,format=raw,if=ide \
  -boot c -vga std

Si tu equipo tiene poca memoria, cierra otras aplicaciones antes de iniciar la máquina virtual.

4. Qué ocurre al iniciar

En el primer inicio, el asistente Yonata te guía para configurar idioma, distribución de teclado, zona horaria y cuenta local. Después entrarás al escritorio Openbox con Perry Panel.

5. Si algo falla

  • Pantalla negra: espera un poco más y revisa la configuración de vídeo de la VM.
  • La demo no carga: comprueba que libv86.js, v86.wasm, seabios.bin y vgabios.bin estén en la carpeta web/.
  • Descarga interrumpida: vuelve a intentarlo desde Descargas.
  • Error del sistema: abre un issue en GitHub e indica qué edición probaste.
