🍓 Perry Pi OS

Entorno ligero inspirado en Raspberry Pi OS con arranque estilo consola, MicroPython, Python 3 y escritorio rápido.

  • Arranque clásico en texto: Visualiza el kernel y servicios cargando en consola antes del escritorio.
  • Listo para programar: Incluye MicroPython, Python 3, LXTerminal y navegador web ligero.
  • Multiplataforma: Ejecútalo directo en tu navegador o descárgalo preinstalado para VMware y VirtualBox.
