Arranque rápido en tu PC

Para probar el emulador localmente, sirve la carpeta web mediante HTTP. No abras la demo como archivo file:// porque el navegador puede bloquear WASM y las peticiones de disco.

1. Iniciar el servidor

cd web
python3 app.py

2. Abre http://localhost:8080 y pulsa «Iniciar demo web».

3. Si el disco no carga automáticamente, selecciona un archivo .img o .img.gz desde la demo.

Preguntas frecuentes

Detalles importantes antes de instalar o probar el sistema.

¿Perry Pi OS es Raspberry Pi OS oficial?

No. Es un proyecto independiente basado en Debian 12. Las compilaciones actuales son i386 y amd64, no imágenes ARM oficiales para Raspberry Pi.

¿Puedo probarlo sin instalar nada?

Sí. La edición Web usa v86 para ejecutar la imagen i386 en el navegador. La primera carga puede tardar y requiere descargar una imagen grande.

¿La ISO amd64 ya está disponible?

La ISO forma parte de los objetivos de compilación del proyecto, pero no aparece entre los dos archivos de la última Release que se verificó al preparar esta página. Consulta Releases o GitHub Actions para comprobar una publicación posterior.

¿Puedo usar la imagen como sistema principal?

El proyecto está en desarrollo. Primero pruébalo en una máquina virtual y haz copias de seguridad. Comprueba la compatibilidad del hardware antes de instalarlo en un equipo real.

¿Dónde reporto errores?

Abre un issue en el repositorio de GitHub e incluye la edición, arquitectura y el mensaje de error.
